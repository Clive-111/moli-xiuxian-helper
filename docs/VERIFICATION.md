验证日期：2026-10-05。测试使用隔离的本地页面、临时数据和浏览器；不连接使用者的 Discord 账号。

- 原有战斗与物品回归：303 项，其中 302 项通过，1 项 Linux 专用测试跳过。
- 首次绑定和设置：新增 9 项通过，涵盖任意完整姓名、重复/隐藏姓名、弹窗、确认时人物变化、过期确认、未绑定接口限制、归属校验、重启和手机布局。
- 原生启动：新增 1 项通过，验证从其他工作目录启动、目录含空格、未登录时面板可用、端口冲突不影响先前实例。
- 最终面板定向回归通过，覆盖首次绑定及原有 SSE 草稿保存、地图选择和窄屏。
- 首次打开登录窗口修复：16 项相关测试通过，新增覆盖未登录时立即交还操作、重复打开保留手动输入、网络失败后重试、启动器不被自动点击，以及 SSE 完成早于 HTTP 回执时不残留“排队”提示。
- 修复后的 Windows 实例实测：打开独立浏览器约 0.6 秒完成，队列释放，保持未绑定及停止；此检查不执行人物绑定或游戏消费。
- 浏览器关闭与面板进程分离：71 项相关回归通过。真实独立浏览器关闭后 HTTP 面板仍响应、明确打开可重新创建浏览器并保留登录资料；关闭期间的旧读取和排队请求作废，已绑定实例保存停止及关闭状态，保留待核对记录。
- 网页登录入口修复：35 项定向回归通过。首次打开及直接读取都先进入 `/login`；“Discord APP 已开启”页面立即暂停并可返回网页登录，重复打开不清除正在输入的登录内容。
- 绑定后状态读取及游戏弹出窗口修复：93 项相关回归通过。绑定完成立即显示地点、气血和时间；停止时只读刷新，人物变化保留上次有效记录并提示。频道与弹出窗口之间切换、关闭原频道、重复游戏界面及活动窗口崩溃均有覆盖；只读刷新不点击启动器或游戏按钮，关闭游戏后不再读取或重连。
- 修复后的 Windows 实例在已有绑定和登录下重新连接成功，读到实际位置及完整气血，随后自动刷新时间持续推进；挂机保持停止，此检查未发起战斗、撤退或消费操作。
- 打开后完整资料同步：89 项相关回归通过，覆盖确认绑定、重新打开、阶段进度、单项失败保留缓存、人物变化和弹窗暂停、关闭中断、重复请求合并、接口校验，以及面板自动填充战斗/调息选项与物品列表。
- 实机启动发现 Discord 菜单切换期间旧标题可能失效，已增加点击前状态复核和有界重读；74 项相关回归通过（含新增竞态用例）。真实面板点击「打开游戏」后自动完成四项读取，核对各项更新时间均前进，页面无 JavaScript 错误，挂机保持停止；未进行炼制、出售、换装或消费验收。

- 游戏原生批量售出：55 项相关回归通过，覆盖按编号混合勾选器物和炼材、清空旧选择、同名同品质、重复穿戴显示、名单/品质/单价变化、1000 件分组、叠加材料的确认数量、筛选复位、部分或未售出、保存延迟、点击回执丢失、持久化失败、中途停止、重启只核对及面板逐项待核对数量；保留旧界面的逐件出售回归。这些售出测试均使用模拟物品。

## 验证边界

- 未在新安装的真实 Discord 账号上执行战斗、炼制、卖出或换装；不把模拟页面测试视为真实消费验收。
- Windows 原生与 Linux 容器已验证；macOS 原生不是本版支持范围。
- 人物核对基于游戏显示的完整姓名，不读取账号凭据，无法保证区分完全同名的不同账号。
- 同一游戏账号只运行一个实例。换号和改名使用独立运行目录，不提供旧个人运行数据的自动迁移。
